## Overview

A full-stack e-commerce project with product discovery, customer accounts, shopping carts and order management. My role in the repository is listed as Java backend maintainer; design and frontend work are credited to a collaborator.

## Approach

The backend is organized into domain, infrastructure and application layers and uses Spring Modulith to structure its modules. The documented feature set includes product management, ordering, stock management and administration.

## Technical details

The project uses Java and Spring Boot, with Auth0 documented for account authentication. Development services are configured with Docker.
