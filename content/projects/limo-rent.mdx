## Overview

Limo Rent combines a rental website with content management features. The project brings a Next.js frontend and a Spring Boot backend together in one application.

## Approach

The frontend uses React components, animated transitions and validated forms. MDX supports content authoring, while the backend provides the Java service layer and API documentation.

## Technical details

The repository documents Next.js, Tailwind CSS, Framer Motion, Spring Boot, MapStruct and SpringDoc. H2 is used for the development database.

## Access

The source repository is public. The project README describes the implementation; deployment and business results are not documented there.
