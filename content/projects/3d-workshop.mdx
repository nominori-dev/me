## Overview

3D Assets Workshop is a backend for an online shop built around 3D assets. Its REST API provides the application layer for managing and selling those assets.

## Approach

The service combines a Spring Boot API with PostgreSQL, authentication through an OAuth2 resource server and Keycloak, and RabbitMQ messaging. Liquibase handles database migrations.

## Technical details

The repository includes Docker-based development services and API documentation with SpringDoc. It is an archived project, preserved here as an example of backend architecture and integration work.
