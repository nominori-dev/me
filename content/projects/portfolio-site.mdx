## Overview

This portfolio brings together selected work, a concise introduction and project case studies in a single Next.js application.

## Approach

Project content lives in local MDX files and is validated with Zod. This keeps publishing straightforward without adding a database or a separate content management system.

## Stack

Next.js, React, TypeScript, MDX and Three.js.
