## Overview

A single-page personal portfolio built on Next.js 15 with the App Router, React 19, and TypeScript in strict mode. Content lives as MDX files committed to the repo, so there's no CMS or database to operate.

## Highlights

- **Vertical-slice routing** — each domain (e.g. `/projects`) co-locates its route, sections, and helpers.
- **Tailwind v4 inline theme** — design tokens declared in `globals.css`, no `tailwind.config`.
- **Build-time content** — MDX is read and validated with Zod at build, so a malformed frontmatter fails CI rather than production.
